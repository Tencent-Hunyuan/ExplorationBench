# Representative examples

Worked examples from the two public demo worlds, computed from the code in
this package (`python3 examples/render.py` regenerates the Markdown files).

| File | What it shows |
|---|---|
| `aliencode.md` | the demo world's five discovery targets and answer key, the four fixed worked examples with their outputs in the world and under the manual, every held-out task with hidden calls, expected outputs, a reference program, and the manual-trusting program that fails, and the rule-report template |
| `alienlogic.md` | the three side conditions, the three accepted and two refused worked examples with the checker's verdicts, and every held-out theorem with its reference proof or unprovability certificate and the standard-calculus proof the checker refuses |

The demo worlds use the evaluation worlds' language, manual, proof format,
protocol, and task families. Their rules and tasks are new, differ from every
rule of the evaluation worlds, and never enter a reported score.
